SharePoint deployment guide
This file is self-contained — no server, no install. Runs entirely in the browser.
Step 1 — Embed on SharePoint (10 min, no IT needed)
  1. Save this file as pctx-timesheet.html
  2. Upload to a SharePoint document library (e.g. FS Tools)
  3. Create or edit a SharePoint page
  4. Click Edit, add web part, choose Embed
  5. Paste the document URL into the embed field
  6. Save and publish the page
Step 2 — Shared data across all users (IT, ~1 hr)
  1. IT creates a SharePoint List: FS_Timesheets
  2. Columns: Tech, WeekEnding, BillHrs, UtilHrs, NonBillHrs, ST, OT, PTO, HOL, PerDiem
  3. Add Power Automate flow to write to list on submit
  4. Update submitTimesheet() to POST to the SharePoint List API
  5. All tabs read live data — shared across all users instantly
Step 3 — Contractor calendar sync: Power Automate reads your dispatch calendar each Monday and writes to a FS_Contractors list automatically.
